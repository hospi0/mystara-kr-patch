> 이 저장소에는 도구·번역 텍스트·작업 문서만 있습니다(게임 데이터·빌드 결과물 없음).

| 파일 | 내용 |
|---|---|
| `MystaraEiyuuSenki_PS3_KR_v0.9.zip` | 본편 — EBOOT·글꼴·그림·메뉴 등 20개 파일 |
| `MystaraEiyuuSenki_PS3_KR_v0.9_Movie.zip` | 선택 — 무비 갤러리 대담 영상 3편 한글 자막(약 1.4GB) |

## 적용

1. zip 을 풉니다.
2. `한글패치_적용.bat` 을 실행하고 게임 폴더(`PS3_GAME` 이 있는 폴더)를 끌어다 놓습니다.
3. 파일마다 원본 MD5 확인 → 원본 백업 → xdelta 적용 → 결과 MD5 확인 후 덮어씁니다. 되돌리기는 `되돌리기.bat`.
4. **RPCS3 의 `dev_hdd1\caches\BLJM61055_BLJM61055` 폴더를 지웁니다.** RPCS3 는 게임 데이터를 이 캐시에서 읽습니다.
5. 패치 전에 만든 스테이트는 쓰지 말고 새로 부팅해서 확인하세요.

EBOOT.BIN 은 복호화된 형태라 실기 PS3 에서는 돌지 않습니다.

## 바뀌는 것

- 타이틀 로고, 경고 화면, 메뉴·설정·기록·도움말, 메뉴 글꼴(고해상도 한글)
- **섀도 오버 미스타라**: 대사 전부, 링 메뉴 아이템·마법 이름, 함정 말풍선, 무대 제목, 캐릭터 선택 설명, 이름 입력 버튼
- **타워 오브 둠**: 대사 전부, 가게, 아이템 이름, 캐릭터 선택 설명, 아이템 이름 띠, 이름 입력(영문)
- 저장·트로피 등 시스템 메시지, 저작권 경고, 무비 갤러리 썸네일, 게임 아이콘
- (선택) 무비 갤러리 대담 영상 3편 자막

엔딩 스태프 롤과 설명서는 원문 그대로입니다. 섀도 오버 미스타라의 이름 입력은 일본판 그대로 가나로 입력합니다.
