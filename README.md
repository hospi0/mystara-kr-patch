## 적용

0. **원본 게임 파일에 적용합니다.** 예전 한글 패치(v0.9)를 깔았다면 먼저 그 묶음의 `되돌리기.bat` 로 원본으로 돌립니다.
1. zip 을 풉니다.
2. `한글패치_적용.bat` 을 실행하고 게임 폴더(`PS3_GAME` 이 있는 폴더)를 끌어다 놓습니다.
   1.02 묶음은 이어서 RPCS3 폴더(`rpcs3.exe` 가 있는 곳)도 끌어다 놓습니다.
3. 파일마다 원본 MD5 확인 → 원본 백업 → xdelta 적용 → 결과 MD5 확인 후 덮어씁니다. 되돌리기는 `되돌리기.bat`.
4. **RPCS3 의 `dev_hdd1\caches\BLJM61055_BLJM61055` 폴더를 지웁니다.** RPCS3 는 게임 데이터를 이 캐시에서 읽습니다.
5. 패치 전에 만든 스테이트는 쓰지 말고 새로 부팅해서 확인하세요.

EBOOT.BIN 은 복호화된 형태라 실기 PS3 에서는 돌지 않습니다.
경로에 `&` 같은 기호가 있어도 됩니다(v0.91 에서 고침).

## 바뀌는 것

- 타이틀 로고, 경고 화면, 메뉴·설정·기록·도움말, 메뉴 글꼴(고해상도 한글)
- **섀도 오버 미스타라**: 대사 전부, 링 메뉴 아이템·마법 이름, 함정 말풍선, 무대 제목, 캐릭터 선택 설명, 이름 입력(영문 A~Z·0~9)
- **타워 오브 둠**: 대사 전부, 가게, 아이템 이름, 캐릭터 선택 설명, 아이템 이름 띠, 이름 입력(영문)
- 저장·트로피 등 시스템 메시지, 저작권 경고, 무비 갤러리 썸네일, 게임 아이콘
- **1.02 업데이트**: 네트워크(통신 플레이·게임 만들기·검색·랭킹) 메뉴 문구, 업데이트 내역 그림, 온라인 일시 정지 메뉴, 온라인 시스템 메시지
- (선택) 무비 갤러리 대담 영상 3편 자막

엔딩 스태프 롤과 설명서는 원문 그대로입니다.

### v0.91 에서 바뀐 것

- 섀도 오버 미스타라 이름 입력을 영문 글자판으로(글자 숫자 = 성장 타입 계산은 영문판과 같음)
- 1.02 업데이트 대응(1.02 용 묶음 따로)
- 함정 말풍선 «석화»·«화살» 을 각자 칸에 따로 그림(화살 함정 말풍선이 «!» 만 나오던 것 고침)
- 챕터 선택 무대 이름을 본편 대사와 같은 표기로(아테노스·코룬글레인·란넬즈)
- 배치 파일이 경로의 `&` 에서 멈추던 것 고침
